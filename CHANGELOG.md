# Changelog

## [1.0.0] - 2026-06-01

### Added
- **AI Notes Suite:** Gemini 2.5 Flash implementation for high-retention text guide synthesis.
- **AI Flowcharts & Diagrams:** Mermaid CLI rendering integration with automated syntax check retries.
- **AI PPT Slides:** Full automated slides formatting via PptxGenJS and custom template themes.
- **Billing Framework:** Credit management pipelines, secure packages database, and Stripe Webhook verification.
- **Document Utilities:** Implemented robust PDF-to-Word conversions, file splits, and zipping scripts.
- **Clean Structure Configuration:** Added comprehensive `.gitignore` rules and local configuration models.
- **Project Documentation:** Set up detailed instructions in `README.md`, standard MIT `LICENSE`, and developer configuration templates.
